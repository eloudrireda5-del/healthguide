# مُرشدك الصحي — Health Guide App

تطبيق ويب طبي تثقيفي متعدد اللغات (عربي RTL / English / Français / Italiano) — يعمل مباشرة بفتح `index.html` في أي متصفح، دون خادم أو إنترنت.

## التشغيل
- على الهاتف: انسخ المجلد وافتح `index.html` بأي متصفح.
- على الحاسوب: فتح الملف مباشرة يكفي.

## الميزات المنفذة
1. **مقابلة طبية تفاعلية** — 7 مسارات أعراض (صدر، إمساك، حموضة، صداع، إسهال، عطش/تبول، كحة) بأسئلة نعم/لا.
2. **محرك فرز أمان حتمي** (`js/engine.js`) — يفحص العلامات الحمراء أولًا: طارئ → عاجل → روتيني، مع زر اتصال بالطوارئ.
3. **تشخيصات تفاضلية مرتبة بالاحتمال** مع عدم الجزم (يُعبَّر عن الترجيح لا التأكيد).
4. **الدليل الغذائي** — 14 حالة من قاعدة المعرفة، مع **تخصيص تلقائي** حسب ملف المستخدم (مثال: مرض الكلى → تحذير خاص بالبوتاسيوم).
5. **دليل الأدوية** — 10 أدوية شائعة: الغرض، الفوائد، الآثار الجانبية، التحذيرات، التعارضات.
6. **تحليل التحاليل** — 15 محلولًا بمعدلات مرجعية وتفسير مبسّط (طبيعي/منخفض/مرتفع) وتحذيرات عند الخطورة.
7. **كاشف تعارضات دوائية-غذائية** — يلتقط تلقائيًا من ملف المستخدم (جريب فروت + أملوديبين/سيمفاستاتين، شاي + ليفوثيروكسين...).
8. **ملف طبي محلي** + سجل استشارات — localStorage (يُستبدل بقاعدة بيانات مشفرة في النسخة السحابية).

## البنية
```
index.html      الهيكل
css/style.css   التنسيق (يتجاوب مع الهاتف ويدعم RTL/LTR)
js/i18n.js      نصوص الواجهة باللغات الأربع
js/data.js      قاعدة المعرفة الطبية (الأغذية، الأدوية، التحاليل، المسارات)
js/engine.js    منطق الفرز والسلامة — قابل للاختبار المستقل
js/app.js       الواجهة والتنقل
```

## حدود هذه النسخة (وخارطة الطريق)
- **الترجمة:** المحتوى الطبي الكامل بالعربية والإنجليزية؛ الفرنسية والإيطالية تغطيان الواجهة — تُكمل مكتبات المحتوى بالتدريج.
- **رفع التقارير:** يتطلب خادمًا + OCR (لا يمكن تنفيذه في ملف محلي) — حقل الإدخال اليدوي جاهز حتى ذلك الحين.
- **لا توجد صور أشعة** — يوجه التطبيق لأخصائي بدل التحليل الآلي (قرار سلامة مقصود).
- **الخطوة التالية للإنتاج:** حسابات وBackend مشفّر (مثال: Firebase/Supabase + Node.js)، مراجعة طبيب مرخّص لكل محتوى، وامتثال (GDPR/HIPAA حسب السوق).

## إخلاء مسؤولية
أداة تثقيفية وليست تشخيصًا طبيًا. لا توقف أو تعدّل أي دواء دون إشراف طبي. الحالات الطارئة تتطلب الاتصال الفوري بخدمات الطوارئ.


## ربط Kimi AI (التحقق والمصادر والتحديث)
التطبيق يدعم الاتصال بـ Kimi عبر خادم وسيط آمن (المفتاح لا يُعرض في المتصفح أبدًا):

```bash
# 1) احصل على المفتاح من platform.moonshot.cn
# 2) شغّل الخادم
MOONSHOT_API_KEY=sk-xxxxxxxx node server.js
# 3) افتح http://localhost:3000
```

- تبويب **«اسأل AI»**: أي سؤال صحي → Kimi يجيب بعد فحص علامات الخطر + ذكر مصادر حديثة عبر بحث الويب المدمج.
- زر **«تحقق من هذه المعلومة عبر AI»** في الدليل الغذائي: يدقق محتوى التطبيق مقابل أحدث الإرشادات ويعيد المصادر.
- بدون مفتاح/خادم يعمل التطبيق كاملًا في الوضع المحلي، وتظهر رسالة توضيحية بدل واجهة AI.
- للتحقق اللاحق التلقائي للمكتبة الطبية: `curl -X POST localhost:3000/api/verify -H "Content-Type: application/json" -d '{"topic":"الإمساك","content":"..."}'`
- نموذج افتراضي: moonshot-v1-8k — واضبط `KIMI_MODEL=kimi-k2-...` لتفعيل بحث الويب المدمج.


## النشر على الويب مجانًا (Vercel + حساب Google) — 5 دقائق
المشروع يتضمن دوال Serverless جاهزة (`api/ask.js` و `api/verify.js`) — لا حاجة لخادم خاص.

1. أنشئ حساب GitHub عبر **"Sign up with Google"** (تدخل بحساب Gmail — بدون كتابة كلمة السر في GitHub إطلاقًا).
2. ارفع مجلد المشروع كمستودع جديد (Add file → Upload files).
3. افتح **vercel.com** واضغط **"Sign up with GitHub"** (مجاني).
4. **Add New Project** ← استورد المستودع ← قبل الضغط على Deploy:
   - Settings → Environment Variables ← أضف: `MOONSHOT_API_KEY` = مفتاحك من platform.moonshot.cn
5. اضغط **Deploy** — بعد ~30 ثانية ستحصل على رابط عام مثل `https://healthguide-xxxx.vercel.app`

الآن التطبيق يعمل على الويب لأي شخص، وواجهة AI تعمل بالمصادر، والمفتاح محفوظ في الخادم السحابي ولا يظهر للزوار.

### تحديث لاحقًا
- أي تعديل على GitHub ينشر تلقائيًا (git push → Vercel يعيد النشر).
- البدائل المكافئة: Netlify Functions أو Render (يستعمل `server.js` كما هو).
